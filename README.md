# Система обработки заявок сервисного центра (JADE MAS)

Проект представляет собой мультиагентную систему на платформе JADE, которая моделирует работу сервисного центра: клиенты создают заявки с описанием проблемы, диспетчер принимает их, ведёт очередь и назначает на свободных мастеров, а мастера выполняют заявки и отправляют результат обратно клиенту. В логах отображаются: регистрация агентов, принятие заявки, назначение исполнителя, завершение, ошибка обработки и повторная попытка назначения.

Система поддерживает обработку нескольких заявок одновременно, учитывает занятость мастеров и переносит заявки в очередь, если все исполнители заняты, а при ошибке выполнения инициирует повторное распределение. Проект предназначен для демонстрации принципов взаимодействия агентов, обмена сообщениями и управления очередью задач в распределённой среде.

В актуальной версии системы агенты распределены между несколькими контейнерами JADE, что позволяет моделировать работу распределённой среды. Используются два диспетчера, функционирующие параллельно и конкурирующие за общих мастеров через общий сервис каталогов (DF). В результате возникает ситуация конфликтов назначения, при которых мастер может отклонить заявку из-за занятости, после чего диспетчер повторно помещает её в очередь и инициирует новое распределение.
